# 243 Ways Social 文档

| 文件 | 用途 |
|---|---|
| `243ways_建模拆解.docx` | v1/v2 机制、RTP 拆解、多档 Feature 贡献与面试讲法 |
| `243ways_模型工作簿.xlsx` | Par Sheet、RTP 公式链、Feature 与版本对比 |
